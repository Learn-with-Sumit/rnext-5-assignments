## 🚀 Quick Workflow

1. **Clone Template:** উপরের তালিকা থেকে নির্দিষ্ট অ্যাসাইনমেন্ট ব্রাঞ্চ ক্লোন করুন।
2. **Setup Project:** ক্লোন করা টেমপ্লেট দেখে আপনার প্রোজেক্ট (যেমন React/Vite) সাজিয়ে কোডিং শুরু করুন।
3. **Push to Private Repo:** কাজ শেষ করে নিজের GitHub অ্যাকাউন্টে একটি **Private Repository**-তে কোড পুশ করুন।
4. **Deploy:** Vercel বা Netlify-তে প্রোজেক্ট ডেপ্লয় করে লাইভ লিংক তৈরি করুন।
5. **Submit:** কোর্স প্ল্যাটফর্মে গিয়ে লাইভ লিংক ও প্রাইভেট রিপোজিটরি লিংক সাবমিট করুন।

---

## ⚠️ Important Rules

- **Private Repository বাধ্যতামূলক:** অ্যাসাইনমেন্ট রিপোজিটরি অবশ্যই **Private** হতে হবে। Public রিপোজিটরি সাবমিট করলে অ্যাসাইনমেন্ট বাতিল হবে।
- **Live Preview আবশ্যক:** সাবমিট করার আগে লাইভ সাইট এবং গিটহাব লিংক ঠিকঠাক কাজ করছে কিনা নিশ্চিত করুন।
- **ডেডলাইন সচেতনতা:** ডেডলাইনের পর কোনো কোড পরিবর্তন বা নতুন পুশ গ্রহণযোগ্য নয়।
- **Environment (.env) ফাইল:** অ্যাসাইনমেন্ট রিভিউ করার সুবিধার্থে প্রয়োজনীয় `.env` বা কনফিগ ফাইল রিপোজিটরিতে অন্তর্ভুক্ত থাকতে হবে।
